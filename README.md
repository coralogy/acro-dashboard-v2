1. pip install streamlit
2. to run the app locally: `streamlit run app.py`
3. get all the packages: `pip freeze` -> copy this to your requirements.txt

## to push to github
1. to check what files have changed: `git status`
2. tell git what files to commit: `git add .` -> using `.` commits all the files that have changed
3. to commit the files `git commit -m "nice message"` -> `-m` represents message 
4. push to remote git (github in the cloud) -> `git push`
